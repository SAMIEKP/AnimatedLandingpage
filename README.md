# 🚗 CAR CARE - Animated Landing Page

## Overview
single-page animated landing page for electric & sports car care services. Features CSS-only 3D slider, floating particles, glassmorphism nav, non-scrollable viewport with overlay sections.

## Features
- **3D Car Carousel** (9 high-res images)
- **Floating Particle Background**
- **Glassmorphism MENU Toggle** (5 links: Home/Services/Contact/Gallery/Call)
- **Services Grid** (hover animations)
- **Contact Form** (JS demo submission)
- **Fully Responsive** (mobile-first)
- **No Scroll** (fixed viewport, nav toggles overlays)
- **SEO Optimized** (meta/OG tags)

## Customization
- **Phone**: Replace `tel:+1234567890`
- **Form**: Integrate EmailJS/Netlify
- **Images**: Swap in `Images/`
- **Colors**: Edit CSS gradients (#006D5B green, #FF6F61 orange)

## Tech Stack
- **HTML5/CSS3** (3D transforms, backdrop-filter, clamp())
- **Vanilla JS** (no frameworks)
- **Viewport Units** (vmin/vh/vw)
- **GPU Accelerated** animations

## Browser Support
- Chrome/Edge/Firefox/Opera (latest)
- Safari 13+ (backdrop-filter)
